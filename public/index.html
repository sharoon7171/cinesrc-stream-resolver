Cinesrc Stream Resolver

Turns a TMDB ID into a playable stream from cinesrc.st. It opens the embed route, runs the site challenge, probes providers, and loads the first link that works.

/embed/movie/1084242
Finding IDs — search on themoviedb.org. The number in the URL is what you enter (/movie/1084242 → 1084242, /tv/1396 → 1396). What happens — the resolver loads the Cinesrc embed, passes the PoW challenge, lists providers, and probes them until one returns a stream. Switching providers — after Play, pick another provider under the player.
